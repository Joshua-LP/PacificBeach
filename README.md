## 🏄 Sobre el Proyecto

**Pacific Beach** es la landing page oficial de un condominio exclusivo ubicado en **Playa Punta Bermejo**, a tan solo **4 horas de Lima (KM 222 Panamericana Norte)**. Diseñado para surfistas y amantes del mar que buscan vivir cerca del mejor *surf break* del Norte Chico peruano.

El sitio web presenta los proyectos disponibles, planes de financiamiento y una experiencia visual inmersiva con videos y fotografías del lugar.

---

## ✨ Características

| Funcionalidad | Descripción |
|---|---|
| 🎬 **Hero con Video** | Carrusel de slides con video local y autoplay |
| 🏠 **Sección Proyectos** | Galería de lotes y propiedades disponibles |
| 🤝 **Refiere y Gana** | Programa de referidos con beneficios |
| 📍 **Mapa Interactivo** | Ubicación en Punta Bermejo, Ancash |
| 📱 **Diseño Responsive** | Optimizado para móviles, tablets y desktop |
| ⚡ **Carga Rápida** | Sin frameworks pesados, vanilla JS puro |
