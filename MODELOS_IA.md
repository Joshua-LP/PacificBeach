## 🛠️ Herramientas Disponibles

Como Claude Code, tengo acceso a las siguientes herramientas:

### Operaciones de Archivos
- **Read**: Leer archivos (incluyendo imágenes, PDFs, Jupyter notebooks)
- **Write**: Escribir nuevos archivos
- **Edit**: Editar archivos existentes
- **Glob**: Búsqueda de archivos por patrones
- **Grep**: Búsqueda de contenido en archivos

### Desarrollo
- **Bash**: Ejecución de comandos de terminal
- **Task**: Lanzar agentes especializados para tareas complejas
- **EnterPlanMode**: Planificar implementaciones antes de ejecutarlas

### Control de Versiones
- **Git**: Operaciones git completas (status, diff, commit, etc.)
- **GitHub MCP**: Interacción con GitHub API
  - Gestión de pull requests
  - Revisión de workflows y CI/CD
  - Análisis de issues y comentarios

### Navegación Web
- **Playwright MCP**: Automatización de navegador
  - Navegación web
  - Toma de screenshots
  - Interacción con elementos web
  - Evaluación de JavaScript
